## Decisões

- `/saude` público com dados mínimos (exceção pública explícita); 503 quando o banco não responde, sem expor erro.
- `trust proxy = 1` (e não `true`) para não aceitar `X-Forwarded-For` arbitrário encadeado.
- Healthcheck do app com `wget` (busybox da imagem alpine); Caddy espera app saudável.
- `POSTGRES_PASSWORD` documentada como alfanumérica porque compõe a `DATABASE_URL`.
- `docker-compose.yml` de desenvolvimento não alterado.
