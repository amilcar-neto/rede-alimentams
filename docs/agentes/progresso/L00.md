## Limitações

- Nenhuma validação de interface, deploy, VPS, revisão independente ou aprovação humana realizada nesta etapa. Não houve mudança de interface.
- Node 24 é o ambiente validado, incluindo `--test-isolation=none`. Se o sistema operacional terminar o próprio runner à força, sua rotina de cleanup não pode executar.
- Assinaturas de pendências são respostas públicas; uma causa interna diferente com resposta idêntica exige leitura dos logs.
- Não foi iniciado outro controlador para validar retomada: esta implementação usa o ambiente fornecido pelo controlador existente; a repetição dos testes e eventual revisão cabem a ele.
