## Decisões

- Quantidade aceita número JSON ou string decimal (compatibilidade com o formulário), até duas casas decimais para corresponder ao NUMERIC do schema; 0 < kg <= 10.000.
- CNPJ obrigatório, aceito com máscara completa ou 14 dígitos, armazenado apenas com dígitos. Sem consulta externa ou uso de dados reais.
- Senhas mantêm seus caracteres originais; rejeitar vazio após trim e limitar a 72 bytes (limite do bcrypt). Não normalizar senha silenciosamente.
- IDs limitados ao INTEGER positivo do PostgreSQL; bairros consultados como propriedades próprias. Campos desconhecidos serão rejeitados; reserva continua aceitando corpo ausente ou objeto vazio.
- Login sem credenciais mantém 401 conforme verificação histórica; tipos e formatos inválidos recebem 400.
